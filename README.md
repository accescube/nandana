# Nandana Sreekumar | Consultant Psychologist Portfolio

A personal portfolio website for **Nandana Sreekumar**, Consultant Psychologist (M.Sc. Psychology, School of Behavioural Sciences, Mahatma Gandhi University).

> *"Creating a safe space to understand, heal, and grow."*

---

## 🌟 Key Features

- **Luxury Blue & White Aesthetics**: Modern, soothing, and high-contrast palette tailored for mental health and clinical consulting.
- **Therapeutic Approach & Pillars**: Structured presentation of active listening, confidentiality, evidence-based practices, and collaborative healing.
- **Areas of Specialization**: Filterable categories covering Counselling & Therapy, Clinical Mental Health, Child & Adolescent Guidance, CBT, and Health Psychology.
- **Psychological Assessments**: Overview of clinical interviewing, MSE, diagnostic report writing, and documented standardized assessment batteries (Personality, Intelligence, Neuropsychology, and Projective tools).
- **Academic Research**: Highlighting empirical studies in *Dispositional Optimism & Indecisiveness*, *Trait Emotional Intelligence & Nature Connectedness*, and statistical proficiency with **SPSS**.
- **Leadership & Community**: Showcasing roles as NSS Secretary, Department Secretary of Psychology, and NEP Saarthi.
- **Interactive Consultation Booking**: Responsive consultation request form with client-side validation, confirmation modal, and direct **WhatsApp quick-booking integration**.
- **Crisis Helpline Notice**: Ethical crisis banner with direct access to national 24/7 emergency mental health lines (Tele-MANAS 14416, Kiran, Emergency 112).

## 💻 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/accescube/nandana.git
   ```
2. Open `index.html` in any modern web browser or serve via Apache / XAMPP:
   ```bash
   # Place in xampp/htdocs/NANDANA and visit:
   http://localhost/NANDANA/
   ```
